# GitHub Release v1.3.1

Adds compact guidance for learning from actual release work. Capture new, actionable failures and recoveries, corrections, missing guidance, and methods that improved results in existing project records. Keep evidence, skill version and scope with each finding; link duplicates and skip routine success and speculation.

Required quality checks stay first. The guidance calls for no extra scans or experiments and keeps lessons out of installed skills and caches. Supported lessons move through a validated source update; capture alone does not authorize a release or installation.

The six host package formats, helper interfaces and MIT license remain unchanged. This release does not update installed hosts automatically.
