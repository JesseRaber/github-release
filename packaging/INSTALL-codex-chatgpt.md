# Install - GitHub Release (Codex / ChatGPT plugin)

For a standalone skill upload use `-UNIVERSAL-skill.zip`.

This archive is a skills-only OpenAI plugin: `.codex-plugin/plugin.json` plus `skills/github-release/`. Extract the outer `github-release/` folder to a permanent location and add it to a local plugin marketplace with Plugin Creator in ChatGPT Work mode or Codex.
